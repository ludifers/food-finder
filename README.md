# Food Finder

Food Finder is a UCF-area restaurant matching app for finding places around
campus without endless scrolling.

The app focuses on UCF, Knights Plaza, University Blvd, Alafaya Trail, Waterford
Lakes, Research Park, Oviedo, and nearby East Orlando food spots.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
